# AIlex reviewed knowledge

This directory contains current, player-facing HauntedMC help. Each file covers one subject so retrieval can return a precise answer. Do not add changelogs, dated snapshots, retired modes, or duplicate facts here.

Files in `index.txt` are overwritten on plugin startup. Files in `retired.txt` are former bundled files that are removed during the upgrade; use new filenames for operator-authored knowledge.

Every player-facing fact must cite a real official HauntedMC page, reviewed current ServerFeatures/ProxyFeatures documentation, or official upstream documentation for a plugin whose installation has been confirmed in the current HauntedMC plugin inventory. Upstream documentation is authoritative for a plugin's normal player controls and behaviour; it is never proof that a feature, rank permission, world, price, reward, timer, or backend is enabled live. For a live value, live server state and the relevant in-game command win. Never infer an exact command, rank, channel, price, schedule, or limit from an old page.

Knowledge documents use front matter. Keep facts concise, current and player-safe. Never store credentials, private reports, internal staff notes, private player data, security details, or exploit instructions.
