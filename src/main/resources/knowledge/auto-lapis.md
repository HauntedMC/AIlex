The current Survival Rank page lists AutoLapis from Supreme. It can place temporary lapis in an enchanting table's lapis slot for eligible players. It only appears when that slot is empty, refills after an enchant while the same menu remains open, and is removed when the menu closes. The feature itself can be enabled on any current game mode.

AutoLapis does not change experience costs, enchant choices, or the item being enchanted. Real lapis already in the slot remains yours and is left alone. The temporary lapis cannot be taken or moved into your inventory.
