Use `/list` to see visible players on your current server. Use `/list <server>` for a registered server when it is available to the list command. Use `/glist` for visible player counts across the network and clickable server actions.

Hidden or vanished players are omitted from names and counts. The network total can include players on servers that are deliberately hidden from the detailed list, so it may be higher than the visible rows add up to.
