The current Survival Rank page lists Night Vision from Supreme. Use `/nightvision` to toggle the server's Night Vision perk when it is available to you. There is no `/nv` command alias.

The choice lasts only for your current session. If you had a normal Night Vision effect before enabling the perk, the remaining part of that effect is restored when the perk is turned off; an effect supplied by another system is not overwritten.
