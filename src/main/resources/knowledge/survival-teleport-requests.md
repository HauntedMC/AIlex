Use `/tpa <player>` to request teleporting to a player. The recipient can use `/tpaccept` or `/tpdeny`; use `/tptoggle` to control whether you receive requests. `/tpahere` requests that a player teleports to you.

The current rank page lists `/tp <player>` from Elite. Use `/back` to return to the last location saved by the server. Teleport requests, `/back`, `/tp`, and `/spawn` remain subject to the current world, combat, cooldown, and safety rules.
