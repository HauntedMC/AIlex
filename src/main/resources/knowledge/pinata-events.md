HauntedMC has PinataParty installed. When a Piñata event is announced, use the announced world and coordinates, then follow the live event message and boss bar. The event can move the Piñata, limit hits per player, require a recent vote or a permitted item, and award configured rewards for hits or the final hit.

Do not promise a spawn time, vote threshold, reward, or participation condition from another server: all of those are live event settings. If you cannot damage the Piñata, read the current event feedback before assuming it is a bug.
