The current Survival Rank page lists a 27-slot `/backpack` from Elite, 36 slots from Legend, and 54 slots from Supreme and Supreme+. Use `/backpack` when the perk is available; live game feedback controls access.

HauntedMC uses Minepacks for this personal storage. Minepacks can restrict use by world or game mode and can impose a cooldown, so the current rank page and in-game response—not a generic Minepacks default—decide where and when your backpack opens.
