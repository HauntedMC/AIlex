The current Creative Rank page lists WorldEdit from Elite. Its published block limits per action are 50,000 for Elite, 100,000 for Legend, 500,000 for Supreme, and 1,000,000 for Supreme+.

Core commands include `//wand`, `//pos1`, `//pos2`, `//set`, `//replace`, `//walls`, `//copy`, `//paste`, `//undo`, and `//redo`. Use a selection before running an edit and keep every operation inside your own plot.

Legend adds published terrain and generation tools such as `//green`, `//flora`, `//forest`, `//naturalize`, `//generate`, `//caves`, `//ore`, and `//setbiome`. Supreme adds advanced brushes and selection tools. Use `//help` and the current WorldEdit feedback for the exact syntax and any live restrictions.
