## Current network
Founded 5 April 2013. Player address: `play.hauntedmc.nl`; website `https://hauntedmc.nl`; Store `https://store.hauntedmc.nl`.

Current game-mode categories: **Survival, Minigames, Creative**. Old Skyblock/Factions/Prison/KitPvP references are historical. Use `/menu`/live state for exact currently available servers/minigames.

Recommended client version: **26.2**; older 1.21.x/26.1 entries are history. Latest public changelog also supports the newest Bedrock versions; `/linkbedrock` is the Bedrock link route. Do not invent a Bedrock patch number.

## Language/resource pack
Localization codes: `nl`, `de`, `en`. `/lang <language>` changes preference; `/language` or `/taal` shows it. First-join language can be location-derived and changed later. Public-chat moderation separately uses Dutch primarily and permits English; staff may request Dutch/English for moderation.

A global server resource pack is offered on login and supports HauntedMC UI/theme content plus game-mode-specific resources. Do not present older planned custom content as already live without newer evidence.
