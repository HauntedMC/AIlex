The current Survival Rank page lists formatted anvil renames from Legend. When the formatted-anvil feature is available to you, an anvil rename can use supported colour codes, hex colours, and visual MiniMessage formatting such as colours and decorations. Ordinary unformatted anvil renames continue to work normally.

Interactive text features such as click events, hover events, fonts, NBT, selectors, and placeholders are not available in player-entered rename text. Some names and items can be blocked by the current server policy.
