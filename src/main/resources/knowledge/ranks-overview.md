The rank hierarchy is Speler, Elite, Legend, Supreme, and Supreme+. Higher ranks inherit the features of lower ranks. The current official rank pages are split into Global, Survival, Creative, and Lobby features; use `/ranks` or the Rank Information page for the live package information.

The focused pages in this knowledge base record the current published rank features by subject. A command can still be unavailable in a particular world or while a gameplay restriction applies.
