## Plot basics
Creative is the current HauntedMC building mode. Documented plot commands include `/plot claim`, `/plot auto`, `/plot home`, `/plot visit <player>`, `/plot tp <id>`, `/plot list`, `/plot info`, `/plot delete` and `/plot clear`.

Deleting or clearing a plot can destroy work. Do not tell a player to run destructive plot commands casually; explain what they do first.

## Plot access
Documented access-management commands include `/plot trust <player>`, `/plot add <player>`, `/plot remove <player>`, `/plot deny <player>` and `/plot kick <player>`. Exact permission differences between `trust` and `add` should come from current in-game help if a player needs the precise boundary.

## Plot customization
Documented customization routes include `/plot sethome`, `/plot setbiome`, `/plot setdescription`, `/plot flag`, `/plot music`, `/plot middle`, `/plot rate` and `/plot comment`. Plot counts, merge capacity and rank-dependent limits can change; check `/ranks`, `/limits` or the live Store.

## WorldEdit
Common Creative WorldEdit commands documented by HauntedMC include `//wand`, `//pos1`, `//pos2`, `//set`, `//replace`, `//copy`, `//paste`, `//undo` and `//redo`. Availability and block/selection limits can depend on rank/server configuration. Do not invent a current WorldEdit limit.

## Community areas
`/warp city` has historically been a documented Creative community route. Treat named warps as changeable: if the warp is unavailable, use `/warps`, `/menu` or current in-game help rather than claiming a replacement.

## Rules
Creative follows the general current server rules plus any Creative-specific rule/limit shown in game. In particular, inappropriate builds, lag machines, abusive redstone/entity systems, impersonation/trolling and blocking public functionality remain prohibited.
