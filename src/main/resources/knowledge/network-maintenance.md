During global maintenance, new normal logins can be blocked. During maintenance for one game mode, new connections to that mode are blocked and existing players can be moved to the hub after the announced countdown.

Maintenance is not a queue: waiting does not reserve a place. Try again after the live maintenance notice says the affected server is available.
