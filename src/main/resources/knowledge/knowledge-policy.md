## Precedence
For current questions: **live trusted state > operator-confirmed knowledge > newest official HauntedMC source > older official material**. A newer specific fact replaces an older fact about the same subject.

Treat game modes, ranks, Discord identifiers, prices, staff, versions, schedules, rewards, warps and limits as freshness-sensitive. Old posts/store records/listings never make them current again.

Historical material is only for explicitly historical questions and must be phrased as past state. If a current/live value cannot be verified, say so instead of guessing.

## Identifiers
Commands, ranks, currencies, channels, URLs, menu names and game-mode names are exact identifiers: copy trusted spelling/syntax; never translate or invent them.

## Storage discipline
Store knowledge fact-densely:
- keep each stable fact in one canonical article; reference rather than duplicate it elsewhere;
- use compact tables/lists for matrices, limits and command groups;
- remove prose that does not change the answer;
- keep volatile values only when they have clear current authority/date, and mark live state as overriding them;
- keep superseded facts only when they remain useful for historical questions;
- preserve qualifications, exceptions, dates and source precedence when compacting; compression must never change meaning.
