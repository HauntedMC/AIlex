Use `/lottery` to view the current draw. Buy tickets with `/lottery buy [amount|max]` and donate with `/lottery donate <amount>`. `max` buys as many tickets as the live balance and current limits allow.

Use `/lottery claim` for a pending payout, `/lottery history [page]` for previous draws, and `/lottery leaderboard <wins|donations> [page]` for the leaderboards. Ticket price, limits, schedule, prize shares, and currency are live settings, so check the in-game lottery display before spending money.
