Chat can be blocked for excessive capitals, prohibited words, IP addresses, unapproved domains, or repeated spam-like messages. When a message is blocked, change the wording instead of repeatedly sending the same message.

The filter checks normal local chat. It does not automatically filter private messages, commands, signs, books, or system messages. The exact word list, approved domains, and spam threshold are current server policy and are not published here.
