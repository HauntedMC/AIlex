## Game modes over time
HauntedMC has advertised or operated more game modes over its history than are active now. Old public material contains names such as Skyblock, Factions, Prison and KitPvP. Current verified categories are only Survival, Creative and Minigames; historical mode names are for explicitly historical questions only.

## Old ranks and products
Historical store/order traces can contain rank/product names that are absent from the current progression, including `God`. Current progression is Speler, Elite, Legend, Supreme and Supreme+; `Gast` is also a current basic guest tag/status. A historical purchase name is not enough to reintroduce a retired rank.

## Superseded punishment table
An older public "Straffen Overzicht" assigned fixed values such as 7-day mutes, 14/30/90-day bans and a permanent IP ban for particular categories and said normal punishments would never deviate from those standard times.

That fixed table is **not current policy**. The newer 23 June 2026 rules define a broader set of possible measures and explicitly make severity depend on seriousness, intent, damage, repetition, evidence and circumstances. Do not answer a current punishment-duration question from the old table.

## Old rule specifics
Older HauntedMC rules contained details that the 23 June 2026 rules no longer state in the same way, including automatic tolerance of German, a blanket six-month maximum for temporary punishment, exact portal/farm counts, specific old raid/bad-omen/flying-machine restrictions and older forum-only appeal language. Do not quote those specifics as current rules unless a newer game-mode-specific rule or `/limits` independently confirms them.

## Old version/world information
Historical news mentions old 1.20.x/1.21.x/26.1 client versions, older world-border expansions and version-specific vanilla changes. These are history only. The current recommended version in reviewed knowledge is 26.2.
