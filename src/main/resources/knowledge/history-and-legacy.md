Historical only:
- old modes include Skyblock, Factions, Prison, KitPvP; current categories are Survival, Creative, Minigames;
- old store/order traces may contain `God`; current progression is Speler → Elite → Legend → Supreme → Supreme+, with `Gast` as guest/basic status;
- an old punishment table assigned fixed 7-day mutes, 14/30/90-day bans and permanent IP bans and said normal durations would not deviate. This is superseded: 23 Jun 2026 rules make measures depend on seriousness, intent, damage, repetition, evidence and circumstances;
- old rules also contained automatic German tolerance, a blanket six-month temporary-punishment maximum, exact portal/farm counts, old raid/bad-omen/flying-machine restrictions and forum-only appeal wording; not current unless newer rules/`/limits` reconfirm them;
- old 1.20.x/1.21.x/26.1 versions and older border/vanilla updates are history; current recommended version is 26.2.

Use these facts only for explicit historical questions; never let them override current knowledge.
