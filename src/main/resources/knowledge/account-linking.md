Linking is optional, but it is required for your in-game rank on the website and Discord and for configured Discord voice/chat access. Log in on the HauntedMC website, join Minecraft, run `/link`, then open the link shown in chat. If you do not yet have a website account, use `/register` to start the registration flow.

For Minecraft linking problems, create a support ticket. Use the website's account-linking page for the Discord flow; never share a password in game chat.
