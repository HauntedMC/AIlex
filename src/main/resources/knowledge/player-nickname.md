The current Global Rank page lists nicknames from Elite. Use `/nickname <nickname>` to set your nickname and `/nickname remove` to clear it. There is no `/nick` alias.

Nickname length, characters, and allowed formatting follow the current server policy. Formatting does not count toward visible length. A nickname does not change your Minecraft account identity, command identity, skin, tab-list name, or nametag unless the relevant display system is configured to show it.
