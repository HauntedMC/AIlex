## Current category
`Minigames` is one of HauntedMC's three current verified game-mode categories alongside Survival and Creative. Individual minigames/maps rotate or change; the current Server Selector (`/menu`) or live server state is stronger than an old event post.

## Events
HauntedMC has long run temporary and scheduled events, including seasonal event-server content, TnTRun competitions, Partymine-style events, egg hunts, drop-party/community activities and special PvE challenges. These examples demonstrate the event style, not a promise that every named event is running now.

`/event` has historically been the route used for dedicated temporary event servers. Treat it as event-specific: if no current event is announced, do not claim the server is open.

## Event rules
Current server rules and any event-specific rules apply. Cheating, bug abuse, event sabotage, unfair external help, alt-account reward farming, ignoring staff instructions and abnormal interference are prohibited. Team size, kits, scoring, practice periods, signup rules, rewards and opening times come from the specific current announcement.
