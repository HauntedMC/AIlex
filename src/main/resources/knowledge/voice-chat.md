HauntedMC has Simple Voice Chat installed. Install the compatible Simple Voice Chat client mod; joining a voice-enabled server normally starts its setup guide. Press `V` to open the voice-chat menu and select your microphone, speakers, activation method, and push-to-talk key. `M` mutes your voice mode and `N` disables voice chat; keys can be changed in Minecraft's Controls settings.

Use `/voicechat help` for the commands available to you. The normal group flow uses `/voicechat invite <player>`, `/voicechat join <group>`, and `/voicechat leave`, but group access and other controls are live server settings. Never share passwords, private conversation, or personal information merely because voice chat is available.
